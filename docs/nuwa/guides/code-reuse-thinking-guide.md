# 代码复用检查

新增函数、组件、常量或 payload 解析前，先用 `rg` 搜实现、调用方、测试和配置。

## 修改前

- 已有等价函数、类型守卫或组件 variant 时，复用或扩展；避免复制一份后独立演化。
- 通用逻辑重复出现三次、或复杂边界被多个调用方使用时再抽象；一次性简单逻辑留在本地。
- 同一未定型 payload 被多处读取时，在数据所有者旁定义共享解码器、类型守卫和投影。
- 单 crate 私有逻辑留在该 crate；跨 crate 共享领域契约可进入 `types`，不能因此引入 IO/平台依赖。
- 跨 feature 的真实共用 UI/工具放 `web/src/components/` 或 `web/src/lib/`，不为复用制造反向依赖。

## 高风险重复

| 对象                         | 必须一起检查                                              |
| ---------------------------- | --------------------------------------------------------- |
| 模型输入尺寸、类别、量化参数 | 算法包元数据、转换脚本、预处理与后处理                    |
| API 字段、时间单位、空值     | Rust DTO、SQLite、TypeScript 类型与解码器                 |
| 坐标变换                     | 缩放/padding 与逆变换共用参数，测试往返一致性             |
| 平台结果                     | 各后端输出结构一致，数值误差按量化基线验证                |
| 状态转移                     | 集中于 `match` / reducer；派生状态保留源事件 `id` / `seq` |

完整契约由所属专题维护，跨语言不能共享源码时用一致性测试防止漂移。

## 修改后

- `rg` 检查旧值、旧字段及全部分支，覆盖 Rust、C/C++、TypeScript 和配置文件。
- Rust 枚举显式匹配，避免 `_ =>` 掩盖新增变体；TypeScript 使用 [穷尽检查](../frontend/type-safety.md#联合类型)。
- 批量修改回看所有实例；不让展示层、命令和后台处理各自维护一份状态转移。
- 多套实现必须产出同一结果时，优先共享定义；无法共享时加针对差异的回归验证。
