# 动态实时流布防工作台与证据中心控制台 (Subtask 4)

## Goal

在 Web 前端控制台（React 19 + Tailwind CSS + Vite）内，基于 Enhanced FLV + MSE 低延迟实时流实现动态矢量布防工作台（Live Stream Rules Designer），重构证据中心三重视图（违规告警、行迹回溯、识别对账）与算法包管理页面，完成全链路单二进制打包与验收。

## Requirements

1. **动态实时流布防工作台 (Live Stream Rules Designer)**：
   - 彻底废除静态死图标注；
   - 工作台直接嵌入 `<LivePlayer cameraId={id} stream="sub" />`，低带宽、低延迟播放实时视频流；
   - 视频上方覆盖一层透明矢量交互层（SVG / Pointer Events），值班员看着实时走动的人员/车辆，直接在动态画面上点击绘制：
     - 多边形（ROI 区域入侵、Mask 遮罩屏蔽）；
     - 折线绊线（Line，动态渲染箭头与跨越方向 `A->B` / 双向）；
     - 局部预裁剪框（Pre-crop ROI 矩形）；
   - 坐标自适应：无论播放器窗口如何缩放，实时等比归一化至 `[0.0, 1.0]` 相对坐标数组存入任务配置。
2. **证据中心三重视图 (Evidence Center)**：
   - **🚨 违规告警页**：卡片与表格视图，展示 1080P/4K 高清现场大图与特写框，支持一键标记与处理；
   - **📸 抓拍回溯页**：按目标类别（人/车/非机动车）与时间跨度分页检索，呈现行迹回溯时间轴；
   - **👤 识别对账页**：**「现场抓拍特写 | 相似度 94.2% | 底库登记照」** 左右直观对比排版，一秒核验通行凭据。
3. **算法包管理中心 (Algorithm Hub)**：
   - 列表展示当前平台加载的可用算法包（名称、版本、类别、平台标签如 `macos-arm64`、实例数）；
   - 支持上传 `.zip` 算法包并展示后端七步沙箱自检结果（自检通过后即刻热可用）。
4. **低噪监控体验 (Low-Noise Live Viewport)**：
   - 多分屏大屏在日常无违规时纯净播放视频，不推高频噪点框；
   - 发生越界或入侵时，通过 WebSocket 稀疏推送告警事件，界面伴随声音即时弹出告警卡片并定位证据。
5. **单二进制内嵌交付与验证**：
   - 前端构建产物 `web/dist` 由 Rust 宿主 `rust-embed` 编译内嵌；
   - 单命令运行 `./argus`，完成从摄像头接入、实时流布防、AI 识别、证据沉淀到控制台呈现的端到端闭环。

## Acceptance Criteria

- [ ] 布防设计器能在子码流动态实时流上丝滑绘制多边形和绊线，保存后坐标在 `[0.0, 1.0]` 区间精确无误。
- [ ] 证据中心能清晰呈现告警列表、抓拍回溯和人脸/车牌左右识别对账页面，图片加载流畅无裂痕。
- [ ] 前端 `pnpm typecheck`、`pnpm lint`、`pnpm test` 与 `pnpm build` 门禁全绿通过。
- [ ] `cargo build --release` 编译出的单个可执行文件，能在无外置 Web 依赖的情况下独立运行全部前后端功能。
